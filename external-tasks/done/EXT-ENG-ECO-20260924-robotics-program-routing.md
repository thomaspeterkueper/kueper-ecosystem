# EXTERNAL TASK — Cross-project robotics program routing

- **Origin:** KUEPER Engineering / NOXIA
- **Target:** KUEPER Ecosystem
- **Date:** 2026-09-24
- **Status:** done

## Request
Register and govern a cross-project robotics/MiniNode program.

## Responsibility split
- KUEPER Engineering: physical architecture, interfaces, prototype engineering and eventual real-world garden-remodelling swarm.
- KG: canonical entities/relations/IDs.
- OTA: evidence, technical dossiers, maturity/provenance.
- noxia-universe: historical/cultural/industrial canon.
- noxiagame: gameplay, balancing and runtime contracts.
- noxia-realtime: later visualization/control implementation only after contracts stabilize.

Ensure the federated rule remains intact: each repository owns only its domain; cross-repository changes travel as external tasks. The real-world garden robot swarm is a future capital-dependent program, not a current build commitment.

## Abschluss (2026-10-09)

Registriert und geregelt durch `decisions/ECO-ARC-0035-2026-DE.md` (Status: `accepted`).

- Das projektübergreifende Robotik-/MiniNode-Programm ist registriert. Die vom Auftrag vorgegebene Verantwortungsaufteilung (ENG Technik, KG Identitäten/Relationen, OTA Evidenz/Provenienz, NXU Kanon, NOXIA Gameplay/Runtime, ECO Governance) ist dort verbindlich festgehalten.
- Die föderative Regel bleibt unverändert: Jedes Repository besitzt nur seine Domäne, Cross-Repository-Änderungen laufen als External Tasks (`ECO-ARC-0006`, Routing `ECO-ARC-0020`). ECO registriert und koordiniert, erzeugt aber keine technischen oder fachlichen Inhalte.
- Der reale Garten-Umbau-Schwarm ist ausdrücklich **kein** aktueller Bau-, Beschaffungs-, Budget- oder Terminbeschluss; ein Start bleibt eine gesonderte Owner-/Kapitalentscheidung.
- `noxia-realtime` ist am 2026-10-09 nicht in `registry/projects.json` registriert und damit kein gültiges Routing-Ziel. Ein späterer Beitritt setzt eine eigene Registrierungsentscheidung voraus; inhaltlich bleibt die Reihenfolge „erst stabile Kontrakte, dann Visualisierung/Steuerung".
- Kein Repository muss aufgrund dieser Registrierung heute etwas umsetzen.

Die parallelen Programmanfragen (Energy Grid/Lernmodul, Adaptive Industry, Living Infrastructure, Mycology/Ecopoiesis, Planetary Evolution, Planetary Remote Sensing, Planetary Architecture, Mars Settlement Systems Kernel) bleiben eigenständig und werden einzeln bearbeitet.
