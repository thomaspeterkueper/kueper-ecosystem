# Cross-Repository-Programme

Status: aktiv  
Repository: `kueper-ecosystem`

Cross-Repository-Programme bündeln eine fachliche Zielsetzung über mehrere
Repositories. Sie verschieben keine Source-of-Truth-Grenze: Jedes Repository
bleibt für seine Domäne zuständig, und Änderungen in anderen Repositories laufen
als External Tasks.

## Registrierte Programme

| Programm | Rolle | Registrierung | Stand |
|---|---|---|---|
| Living Infrastructure | Integrationsschicht für Mykologie/Bodenökologie, geschlossene Lebenserhaltung, Landwirtschaft, Abfall/Recycling, Planetare Evolution und künftige Ecopoiesis | [`living-infrastructure.md`](living-infrastructure.md) | registriert 2026-11-14 |

## Aufnahme weiterer Programme

Ein Programm wird hier registriert, wenn es mehrere Repositories verbindet und
eine dauerhafte Zuständigkeitsverteilung braucht. Die Registrierung:

1. benennt Zweck, Geltungsbereich und Abgrenzung;
2. ordnet jede Domäne genau einem zuständigen Repository zu;
3. dokumentiert Querverweise zu Nachbarprogrammen;
4. routet konkrete Folgearbeiten als External Tasks in die Ziel-Repositories;
5. verschiebt keine Source-of-Truth-Grenze aus `docs/source-of-truth.md`.
